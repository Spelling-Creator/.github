# Spelling Creator

Spelling Creator was born when my non-speaking brother started to communicate.

We needed lessons to feed that communication, so I made Spelling Creator, where parents and teachers can share spelling lessons.

Spelling Creator was made for the benefit of the world.

## Contributing
Most of the nitty-gritty is done in [the monorepo](https://github.com/Spelling-Creator/spelling-creator). Here are some other repos we work on:

- [Boxy (SC)](https://github.com/Spelling-Creator/boxy): A fork of [Boxy](https://github.com/OmniBlocks/Boxy-gh) for our needs
- [Spelling Creator Board](https://github.com/Spelling-Creator/spelling-creator-board): A very WIP virtual letterboard for tablets
- [Spellophone](https://github.com/Spelling-Creator/spellophone): [espeak-ng](https://github.com/espeak-ng/espeak-ng) compiled to WebAssembly, used by Spelling Creator
- [Open Spelling Lesson Format \(OSLF\)](https://github.com/Spelling-Creator/open-spelling-lesson-format): An open standard for spelling lessons
